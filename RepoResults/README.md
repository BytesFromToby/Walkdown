# RepoResults

Audit runs land here: `RepoResults/<name>/<date>_<hash7>/`, with `LOG.md`, the stage outputs,
and `report/` (`summary.html`, `summary.md`, `full.md`). See `docs/READING-THE-REPORT.md`.

Everything in this folder except this README is ignored by git. A report about someone
else's repository is not published until its author has seen it (coordinated disclosure).
