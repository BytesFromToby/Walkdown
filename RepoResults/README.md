# RepoResults

Audit runs land here: `RepoResults/<name>/<date>_<hash7>/`. The reports (`summary.html`,
`summary.md`, `full.md`) and `LOG.md` are at the top; everything else is under `data/`. See
`docs/RUN-FOLDER.md`.

Everything in this folder except this README is ignored by git. A report about someone
else's repository is not published until its author has seen it (coordinated disclosure).
