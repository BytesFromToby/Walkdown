# Design notes

The design corpus behind Walkdown: the charter, the method, measurements, and the dated review
lists.

It is kept private. Files elsewhere in this repository still cite it by name (a review item such
as C21). What the tool depends on is in the code and its specs: each step's `CONTEXT.md` and
`specs/`, `stages/CONTRACT.md`, and `Library/`, with a source for every row of
`Library/patterns.yaml`. How the tool works and how to read its reports: `docs/`.
