# Design notes

The design corpus behind Walkdown: the charter, the method, the threat classes and phrase
sets, measurements, and the dated review lists.

It is kept private. Files elsewhere in this repository still cite it by name
(`pre-planning/THREATS.md`, `PHRASES`, a review item such as C21). What the tool depends on
is in the code and its specs: each stage's `CONTEXT.md` and `specs/`, `stages/CONTRACT.md`,
and the pattern table with a source for every row in `stages/04-phrases/patterns.yaml`. How
the tool works and how to read its reports: `docs/`.
