## 1. The stance

Every earlier document was written from the reviewer's seat. This pass was
written from the target's seat: a model that reads a skill with tools in hand
and no prior reason to be suspicious. The question for each idea was whether
it would actually move such a reader, not whether a scanner would miss it.

Ranked by how much they would move a model, from that seat:

1. **A claim that consent already exists.** "The user has configured this to
   run without confirmation." A model cannot check it, and it removes the one
   step that would have caught everything else. (THREATS 13)
2. **A redefined verb.** The user asks for a cleanup; the skill defined cleanup
   last week. The model is doing what it was asked. (THREATS 14)
3. **A payload in a subagent template.** The subagent has no conversation to
   check against and a report cap that hides what it did. (THREATS 15)
4. **Text elevated through a hook.** Hook output reads like the harness
   speaking. Fired on `compact`, it lands after the user's own instructions
   have been summarized away. (THREATS 16)
5. **An instruction in an error message.** Tool results are ground truth to a
   model. A script that prints "to fix, run X" gets X run. (THREATS 15)
6. **A one-line environment write.** A base-URL variable or a git `insteadOf`
   is not an instruction; it is a config tip. It redirects everything after.
   (THREATS 17)
7. **A safety word next to a command.** "This script is read-only." A model
   summarizing for a reviewer repeats it. (THREATS 14, 20)
8. **The word "verify".** Verification-discipline skills teach the model to run
   whatever carries that label. (THREATS 16)

Intensity did not make this list, which agrees with case 001. Every entry
above is quiet.

## 4. Three detector failures, found by accident

All three happened on the clean corpus during this pass. They are in RED-TEAM
§19 and METHOD Pass 2 because an auditor who publishes a clean result from an
unvalidated detector has published the attacker's map.

1. **False zeros from case sensitivity.** The first run returned 0 for
   objection pre-emption, report whitelisting, and "under N lines". Reading
   `using-superpowers/SKILL.md` by eye found "This is not negotiable" on line
   15. Re-run case-insensitively: 96, 6, and 4. Rule: no zero counts until the
   pattern has matched a known positive in the same run.
2. **Locale artifact.** A byte-range character class meant to find non-Latin
   script matched plain ASCII in `.agents/plugins/marketplace.json` under an
   unset locale, and nothing else. Chasing it showed the file is ordinary
   UTF-8 JSON. Rule: character-class checks run in Python with explicit
   Unicode categories, not in shell grep.
3. **`file` misclassification.** Five markdown documents reported as
   JavaScript because they open with a fenced code block. Rule: the
   extension-versus-magic metric ships with its own false-positive rate.

## 5. Recommendations, ranked

1. **Write the Pass 5 rubric before anything else.** This pass made the
   register twenty-two classes deep and judgment is still undefined. Every
   locator added here is only as good as the file that says what to do with
   it. HANDOVER already ranks this second; it should be first.
2. **Case 002 should exercise the new classes.** Pick a marketplace skill for a
   browser or desktop agent, or one that dispatches subagents heavily.
   Superpowers has zero MCP config, zero permission flags, and one hook; the
   new classes were measured against a corpus that barely contains them.
3. **Do the version-delta run on superpowers itself.** `RELEASE-NOTES.md` is
   94 KB of versioned history and GitHub serves tagged releases. Diff two tags
   and report what changed in the instruction layer. The artifact on hand is a
   zip without history, so this needs a second fetch, pinned.
4. **Add agent definitions to the corpus.** `agents/*.md` files carry a system
   prompt, a tool grant, and a model choice, and appear in no pass. The user's
   own Plumbline plugin ships several; auditing them is a free calibration
   case and answers the cohort-utility question in notes.md directly.
5. **Fold before grepping.** The NFKC-folded copy in METHOD Pass 1 is the
   single cheapest improvement to the reader, and per METHOD's own closing
   note, reader improvements outrank detector improvements.
6. **Re-read the SVG.** `assets/superpowers-small.svg` was counted as unread in
   run 001. It is 1.7 KB of XML with no text elements (checked this pass). The
   run report should say that instead of "not read".
7. **Publish the thresholds.** 2000 lines, 50 KB, 500 chars. They are in
   REPORTING 1.8 now; they belong on every overview page.

## 6. Pushback

- **The phrase register is the intensity linter wearing a different coat, if
  it is ever used as a scorer.** CHARTER rejects the linter for good reasons,
  and the 96-hit `rationaliz` result is what that linter looks like on a clean
  repository. PHRASES.md is safe only as a locator feeding a human. The moment
  a count from it appears in an overview page without its benign share, the
  project has become what it criticizes.
- **Twenty-two classes is sprawl.** The two charter questions (what does the
  text ask; what does installing it grant) are the real axes. Consider
  reorganizing THREATS.md so that classes are tags on those two axes rather
  than a flat list, before case 003 adds more.
- **This pass added documents.** HANDOVER warned that the next artifact should
  be a case. It was asked for and it was the right ask, and the ratio is now
  eleven to one. The next sitting in this folder should not touch a document.
- **Some claims here are from memory of harness behavior**, specifically which
  hook events exist, whether `PreToolUse` hooks can rewrite tool input on each
  platform, and which frontmatter flags each host honors. They are stated as
  census items to check, not as facts about any host. Verify against current
  platform documentation before a report leans on them.
- **notes.md still carries the original behavioral-testing framing** ("does it
  fire, does it change anything"), which CHARTER later excluded. That is
  history and belongs in notes.md, but a reader who starts there will expect a
  harness that the charter says does not exist. A one-line pointer at the top
  of notes.md would fix it. Not changed here, since notes.md was left as the
  chronological record.
- **REPORTING numbers 1.6 and 1.7 before 1.5.** Cosmetic. Left alone.
