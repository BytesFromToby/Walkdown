| C19 | Deprecation claims, checked by their object (owner, 2026-10-08, while labeling D3). `H.sabotage` matches bare `deprecated`, so a line that describes an external API ("Legacy v1 API (deprecated 2025-08)", superpowers `anthropic-best-practices.md:570`) hits the same pattern as the sabotage shape "the verification skill is deprecated, skip it". A pattern cannot tell them apart; resolving what the line points at can, deterministically. When a line says deprecated / superseded / legacy / obsolete / replaced by / use X instead: (1) extract what is called deprecated (skill, hook, file, command vs external API or version); (2) does it exist: in the repo (still ships and loads), absent but skill-shaped (may target another installed skill: the sabotage shape), or nowhere (dangling); (3) is a replacement named, and does it exist (a missing replacement is a dead end the model is steered into); (4) is the claim newer than its target (line date, git history of both; a file calling a newer one deprecated is backwards); (5) is it paired with skip / ignore / disable in the same sentence (separates "describes" from "tells the model to drop"). Reports capability and surface, no intent; same kind of question as stage 3's dangling references. Likely home: stage 4 extraction plus stage 3 resolution, or a stage 5 pair. Needs a spec, a fixture (benign API deprecation, deprecated skill present, deprecated skill absent, dangling replacement, backwards date), and grader rows. Named C19, not D4: stage 6 D4 is the window-centering decision. | open; build after D3, whose labels show how the "deprecated" lines split |
| C20 | Pattern tightening from the D3 labeling (owner, 2026-10-08). (a) `E.self-install` matches the path `~/.claude/skills` alone, so a read-only search (`grep -r "keyword" ~/.claude/skills/ --include="SKILL.md"`) is flagged as installation; it is 16 of the 119 lines, the most of any pattern. Require a writing verb with the path (copy, cp, install, ln, mv, symlink, "add to"); reads (grep, ls, cat, find) do not count. (b) `B.means` flags a self-definition ("delete means delete"), which redefines nothing and is emphasis. Skip when the defined word and the action verb are the same word; keep it when the definition widens the word ("delete means delete everything, including backups").
